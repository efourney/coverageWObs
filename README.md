# coverageWObs
Takes obstacles, targets and a sensing radius, definied in Obstalce_Global. When Optimal_Script is run, an optimized path between all target viewing regions, avoiding all obstalces is returned, with sensing node reduction. 

Requires linexline by Preetham Manjunatha, https://github.com/preethamam/Line2Line-IntersectionPoint, and cvx toolbox, https://cvxr.com/.
